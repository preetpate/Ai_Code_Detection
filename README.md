# AI-Generated Code Detector (Advanced ML/DL Project)

Detects whether a piece of source code was written by a human or generated by
an LLM (GPT-4, Claude, CodeLlama, Copilot, etc.). Combines classical ML on
hand-engineered features, a fine-tuned transformer (CodeBERT), and a
perplexity-based zero-shot detector — plus SHAP explainability and a demo UI.

## Why this is "advanced level"

- **Three complementary detection paradigms**, not just one model:
  1. Feature-engineered classical ML (interpretable, fast, good baseline)
  2. Fine-tuned code-transformer classifier (CodeBERT / GraphCodeBERT)
  3. Perplexity/entropy-based zero-shot detection (DetectGPT-style, no
     training needed, works on unseen model families)
- **AST-aware feature engineering** — not just bag-of-tokens/regex, but real
  structural analysis of the parsed syntax tree.
- **Cross-model generalization evaluation** — train on one LLM's outputs,
  test on another's, to measure how detection transfers.
- **Adversarial robustness check** — measures how much simple obfuscation
  (renaming variables, reformatting) degrades detection.
- **Explainability** — SHAP values show *why* a sample was flagged.
- **Ensemble scoring** — combine all three signals into one calibrated score.

## Project structure

```
ai_code_detector/
├── src/
│   ├── data/
│   │   ├── generate_ai_code.py      # Calls LLM APIs to generate labeled AI code
│   │   ├── collect_human_code.py    # Pulls human code from local/git sources
│   │   └── build_dataset.py         # Merges + splits into train/val/test CSV
│   ├── features/
│   │   ├── ast_features.py          # Structural features from the AST
│   │   ├── style_features.py        # Naming, whitespace, comment style features
│   │   └── extract_features.py      # Orchestrates feature extraction -> DataFrame
│   ├── models/
│   │   ├── baseline_ml.py           # XGBoost / RandomForest / SVM baseline
│   │   ├── codebert_classifier.py   # Fine-tunes CodeBERT for binary classification
│   │   ├── perplexity_detector.py   # Zero-shot detector using code-LM perplexity
│   │   └── ensemble.py              # Combines the three signals
│   ├── explain/
│   │   └── shap_explain.py          # SHAP explanations for the baseline model
│   └── evaluation/
│       ├── cross_model_eval.py      # Train on model A, test on model B
│       └── robustness_eval.py       # Variable renaming / reformat attacks
├── app/
│   └── streamlit_app.py             # Paste code -> get verdict + explanation
├── train.py                         # End-to-end training pipeline entrypoint
├── requirements.txt
└── README.md
```

## Setup

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

You'll need an API key for at least one LLM provider to generate AI-code
samples (set `ANTHROPIC_API_KEY` and/or `OPENAI_API_KEY` as environment
variables). If you don't have API access, you can substitute a public dataset
such as `codeparrot/github-code` for the human side, and any of the several
public "AI vs human code" datasets on Hugging Face for the AI side — swap the
loader in `build_dataset.py`.

## Quickstart

```bash
# 1. Build the dataset
python -m src.data.build_dataset --languages python --n_problems 300

# 2. Extract features
python -m src.features.extract_features --input data/processed/dataset.csv --output data/processed/features.csv

# 3. Train the baseline classical model
python -m src.models.baseline_ml --features data/processed/features.csv

# 4. Fine-tune the transformer classifier (needs GPU for reasonable speed)
python -m src.models.codebert_classifier --data data/processed/dataset.csv

# 5. Run cross-model generalization + robustness evaluation
python -m src.evaluation.cross_model_eval
python -m src.evaluation.robustness_eval

# 6. Launch the demo app
streamlit run app/streamlit_app.py
```

## Evaluation metrics to report

- Accuracy / Precision / Recall / F1 / ROC-AUC per model
- Confusion matrix
- Cross-model transfer matrix (train-model x test-model heatmap)
- Accuracy degradation curve under increasing obfuscation strength
- SHAP summary plot of top discriminative features
